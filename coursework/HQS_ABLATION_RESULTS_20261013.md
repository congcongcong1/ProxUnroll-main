# 12000 步 HQS 续训与双因素消融结果

本页由已完成的训练审计、独立浮点复核和原始 CSV 生成。正百分比表示误差下降，负百分比表示误差增加。

## 实际完成状态

原配方从 10000 步完整状态继续到 12000 步，新增 2000 步，验证选择第 11500 步。另有四种配方各两个种子、每组 800 步，共 6400 步。正式新增更新总计 8400 次；预检另有 14 次更新。全部训练任务退出 0，六个测量因子固定，完整恢复状态、损失/梯度、原图/裁剪/采样配对和验证选模均通过审计。

续训耗时 53.09 分钟；全部新正式训练合计 212.42 GPU 分钟。峰值分配显存 10.84 GiB。GPU 分钟是各任务耗时之和，不是三张卡并行后的墙钟时间。

## 固定800步消融：两个因素的作用

四种配方从同一官方HQS权重和新Adam开始。每个种子共享原图顺序、裁剪、翻转、采样率和潜在噪声；关闭噪声只改变幅度。中间监督为前五阶段各.01/最终.95，最终监督为最终权重1，总权重相同。

| 配对对照 | 测试噪声 | 两种子平均MSE下降 | 最小 | 最大 | 方向一致 |
|---|---:|---:|---:|---:|---|
| 加训练噪声，固定阶段监督 | 0 | -0.74% | -0.77% | -0.71% | 是 |
| 加训练噪声，固定阶段监督 | 0.01 | -0.43% | -0.45% | -0.41% | 是 |
| 加训练噪声，固定阶段监督 | 0.05 | +8.45% | +8.34% | +8.56% | 是 |
| 加训练噪声，固定最终监督 | 0 | -0.91% | -0.99% | -0.83% | 是 |
| 加训练噪声，固定最终监督 | 0.01 | -0.57% | -0.65% | -0.50% | 是 |
| 加训练噪声，固定最终监督 | 0.05 | +8.55% | +8.49% | +8.60% | 是 |

| 加阶段监督，固定干净训练 | 0.01 | +0.00% | -0.04% | +0.04% | 否 |
| 加阶段监督，固定干净训练 | 0.05 | -0.03% | -0.03% | -0.02% | 是 |

以上是固定800步终点的配对差异。验证选中best的结果在同目录单独保存，不与终点混合。两个种子平均是两个配对改善百分比的平均，每个种子的原始值都可查。

因素主效应另用原始MSE差计算，再按同一官方MSE归一化为百分点；交互项是“有阶段监督时噪声收益 − 最终监督时噪声收益”。它与上表不同分母的相对百分比不能混用。

两种训练种子不够证明稳健显著性。800步的消融解释的是这次短期配方作用，不是此前10000步全部收益的原因；没有消融的数据覆盖、学习率与结构不能强行归因。

## 失败案例与局限

主要测试诊断图 `holdout10000_div2k_0897`，采样4%、噪声0.0、测量种子2026，候选`hqs_12000`相对`hqs_10000`的MSE下降为 -4.97%，PSNR变化-0.2105 dB。这是测试后选出的诊断案例，不参与选模型；若选中模型无退步则明确使用终点案例。

误差图只能定位重建偏差，不能独立证明训练退步原因。仍有灰度模拟、中心裁剪、训练种子少、样本有限和官方预训练暴露未知等限制。
