## 数据与分组

- Kodak24 全部作为这次微调与模型选择的测试集。
- HEVC B：BQTerrace、BasketballDrive、Cactus、Kimono1、ParkScene。
- HEVC E：FourPeople、Johnny、KristenAndSara。
- 每段原始 YUV 取零起始帧号 `0, floor(N/3), floor(2N/3)`，共 24 帧。所有视频均只用于测试。
- BQTerrace 实际有 601 帧、BasketballDrive 有 501 帧，文件比常见标称版本各多一帧。其他视频长度符合标称值。
- 统一空间预处理：中心最大正方形裁剪，再用 OpenCV INTER_AREA 缩放到 256×256。
- PNG RGB 用 OpenCV RGB2YCrCb 取 Y。HEVC 原始 8 位 YUV420p 直接取 Y 平面，保留码值除以 255。
- 原始 YUV 不含自描述范围元数据，记录实际极值/分位数，不根据猜测扩展 TV/full 范围。
- 128 张 DIV2K 训练原图使用固定种子 20261009 选择；16 张 DIV2K 官方验证原图用于选模型。
- 按原始图片分割后才做裁剪，跨分组源图片哈希不相交。这次未完整审计官方预训练的数据暴露。

清单、源文件和处理后图像哈希、视频尺寸/位深/帧数/帧号/范围信息在 `data/`。
这是公开或实验室已有数据，不是自采。对 HEVC 的逐帧推理是单图重建，没有前后帧输入。

CUBLAS 设置是确定性 CUDA 训练所必需的；测量哈希重算也沿用相同的 CPU BLAS 线程设置。

## 训练与完整恢复

没有直接用上游长训练默认值。上游 `TrainData` 存在过大随机裁剪风险，随机种子未由 CLI 固定，
`load_checkpoint` 假设特定包装格式，并把初始化与恢复状态混用。
新入口独立于这些默认值，严格加载模型，区分 `--init` 和 `--resume`。
第一轮固定所有 H/W 参数，256×256 因子统一为主实验 MAT；Adam 只优化重建参数。
保留官方六阶段 proximal trajectory 加权 RMSE，学习率 5e-6、batch=1、float32、梯度范数裁剪 1。
这次改变了训练数据和固定矩阵设置，不能称为精确复现论文训练。

```bash
.venv-linux/bin/python -m coursework.finetune \
  --manifest runs/lab220_20261009/data/train_val.json \
  --output runs/lab220_20261009/train_smoke \
  --max-steps 3 --val-every 3 --max-minutes 5
```

每个训练步骤的数据排序和裁剪由步骤号及固定种子确定。`last.pth` 包含模型、Adam、scheduler、
CPU/CUDA RNG、步数和配置；保存后重新加载，检查冻结的矩阵完全不变。
`best.pth` 只由 16 张验证图在 10%、25% 干净条件的平均 PSNR 选择，初始模型也参与选择。
日志保存损失、验证 PSNR/SSIM、耗时、显存和裁剪坐标。测试集不会参与训练或选模型。
完整状态恢复需要同样的数据、矩阵、学习率、种子及训练源代码合同。

`python3 -m coursework.launch_lab_job NAME 'COMMAND' --gpu GPU_UUID` 在已验证容器中启动 nohup，
独立保存 `logs/NAME.log`、`.pid` 和 `.exit`。进程会在 SSH 命令断开后继续运行。
`.exit=0` 还需要结合 `COMPLETE`、CSV、checkpoint 和验证记录检查，不能单独当作成功证据。

## 本次完成结果

四方法完整评测保存 2,112 条主指标和 6,336 条阶段指标；新旧 HQS 比较保存 1,152 条主指标和 6,912 条阶段指标。
两轮所有浮点重建都重新计算 PSNR/SSIM，最大差异为零；数据、权重、矩阵、源码及测量值哈希检查通过。
原始 HQS 在两轮 384 个重复条件下的指标与测量哈希完全一致，排除了这两轮之间的输入差异。
100 步模型在独立验证集被选为最佳，验证 PSNR 从 29.224 提高到 29.340 dB，冻结矩阵没有改变。

| 数据集 | 10% 干净 PSNR 变化 | 25% 干净 PSNR 变化 | 10% 强噪声 PSNR 变化 |
| --- | ---: | ---: | ---: |
| Kodak | +0.135 dB | +0.146 dB | +0.003 dB |
| HEVC_B | +0.146 dB | +0.185 dB | -0.031 dB |
| HEVC_E | +0.372 dB | +0.310 dB | -0.041 dB |

干净条件确有小幅平均提升；强噪声下 Kodak 基本无改善、HEVC 的 PSNR 略降，而 SSIM 仍有小幅上升。不能说微调在所有条件都更好。
只运行一个训练种子和有限步骤，未据此追加 ADMM 微调或长期训练。下一轮应先预先固定噪声验证方案和训练预算。
所有负向结果保存在 comparison/negative_cases.csv；完整逐图差值在 paired_deltas.csv，各类等权汇总在 paired_summary.csv。
最差 PSNR 回退为 Kodak kodim20、10%采样、噪声0.05、seed2027：-0.328 dB。报告/PPT展示同图的预设首个种子2026，回退-0.248 dB。
