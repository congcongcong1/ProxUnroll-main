# 技术报告连续排版修订（2026-10-14）

旧六页生成器把不同章节预先分配到固定页面，并在该页内容绘制完后调用showPage。图片或一组内容被推到下一页时，后续章节不能回填前页；因此留有大块空白。这是生成器布局问题。

新版独立生成器`coursework/build_flow_report.py`使用连续双栏正文，不给章节指定页面，不做逐章节强制分页。大图在当前栏放不下时，最多让两段后续正文先排入；图与图注一起移动，图序、表序和正文顺序保持。标题后至少留出正文空间；标题与紧接的表格一起移动，小表不拆到下一页。末页在实际自然页数确定后平衡两栏。四图按单栏重新绘制，坐标与图例保留可读尺寸。

最终英文技术报告4页，正文10.2 pt、行距12.5 pt，保留四图和六个表（训练方案表及五个结果表），没有删去原有方法、来源、对比、消融、失败分析、复现和AI声明。新增20k训练与完整回归表，摘要明确主要集MSE未继续改善。图1–4仍描述上一轮12000步/800步实验；图4明确显示11500步模型。本次20k结果是表2和表5，不能混淆。

输出：`output/pdf/technical_report_flow_20261014.pdf`；配套完整文字：同名`.md`。
旧版：`output/pdf/technical_report_ablation_20261013.pdf/.md`原样保留。
